# ZUSA Verification Website

A minimal black verification-success page for **[ZUSA] Official Bot**.

## Design

- Black full-page background
- Green circular background
- White check mark centered inside the circle
- Verification message underneath
- No third-party builder branding

## Roblox OAuth

This page is intended to become the visual success page for the ZUSA Roblox OAuth verification flow.

The Roblox OAuth authorization-code exchange must be handled by a server-side component or secure edge/serverless function. Never expose a Roblox client secret in HTML, CSS, or browser-side JavaScript.
